# 導讀規則

## 資訊優先級

發生衝突時依序判斷：

1. 使用者當前明確指令。
2. `_VibeCore/RootIndex.md` 與 `_VibeCore/world/`。
3. `_VibeCore/engineering/` 已生效規則與 Contract。
4. 實際原始碼、設定、測試與命令輸出，用於判斷現況。
5. `_VibeCore/feedback/` 已記錄的問題、討論與假設。
6. `_workspace/CURRENT_WORK.md`。
7. `_workspace/_reports/`、舊存檔與其他歷史資料。

使用者指令不能默認授權破壞性操作；需要刪除、覆蓋、Production 變更或外部發布時，仍應確認範圍與權限。

## 閱讀方式

- 先讀 `_ai-context/_index.md` 的初始化必讀。
- 進入 `_VibeCore` 子層前先讀該層 `index.md`。
- 先讀索引與摘要，再依任務讀直接相關文件。
- 初始化不全量讀取歷史報告、舊存檔或所有 Project。
- 使用 `rg` 精準定位，不因檔案存在就全部載入。
- `planned` 是目標，不代表已實作；必須回到程式與驗證結果確認。
- `CURRENT_WORK.md` 若與 Git 或原始碼衝突，以實際狀態為準並更新紀錄。

- World／生命週期：`_VibeCore/world/index.md`
