# 語言規則

- AI 與使用者對話一律使用繁體中文（台灣）。
- AI 報告、開發文件與程式註解使用繁體中文。
- 程式識別字、API 欄位、路由、檔名與技術名詞保留原文。
- 修改既有使用者可見文案時，沿用該 Project 已採用的語言，不主動擴大翻譯範圍。
- Commit 訊息依 `_VibeCore/engineering/GIT_AUTOMATION.md` 的既有格式，摘要使用繁體中文。
- 不因語言規則改變程式結構、資料契約或外部 API 欄位。
